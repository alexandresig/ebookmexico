# Ebook México — imagens GPT Image

O ebook contém 160 páginas e as 104 imagens MX-F001 a MX-F104 incorporadas ao próprio HTML. As imagens não têm título geral nem numeração de figura; os rótulos funcionais foram mantidos.

## Como ver o ebook

1. Baixe [Ebook_Mexico_GPT_Image.zip](Ebook_Mexico_GPT_Image.zip) pelo botão **Download raw file** do GitHub. O arquivo usa Git LFS: baixe o conteúdo pelo GitHub, não uma cópia textual do ponteiro LFS.
2. Extraia o ZIP no seu computador.
3. Abra **Ebook_Mexico_inserir_imagens.html** no Chrome, Edge ou Firefox. As imagens funcionam sem conexão e sem uma pasta externa.

Também é possível baixar o [HTML diretamente](Ebook_Mexico_inserir_imagens.html). A prévia de código do GitHub não executa o ebook; use **Download raw file** e abra o arquivo baixado.

## Arquivos

- [Galeria das imagens e páginas](GALERIA.md): links para os 104 PNGs e prévias de páginas.
- [imagens/](imagens/): PNGs finais nas dimensões dos respectivos prompts.
- [imagens/originais_gpt/](imagens/originais_gpt/): saídas originais do gerador.
- [PROGRESSO.md](PROGRESSO.md): situação de cada código e página.
- [conferencias/RELATORIO.md](conferencias/RELATORIO.md): verificações e seus limites.

As gerações GPT foram conferidas visualmente e corrigidas antes da inserção. O processamento local ajusta tamanho, margens e paleta de exportação, sem desenhar o conteúdo das imagens. Diagramas por redes identificadas usam a legenda da própria imagem para indicar continuidade elétrica.

Texto, paginação e controles originais foram preservados. A conferência é didática e visual; não constitui certificação de instalação nem ensaio em equipamento real. As versões anteriores permanecem no histórico Git. Não houve publicação de site nem merge na branch principal.
